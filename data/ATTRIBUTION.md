# 数据来源与许可 / Data attribution

`milan.js`（以及 `raw/` 下的原始下载）来自 **OpenStreetMap**，通过 Overpass API 获取，
范围为米兰市中心 `45.450,9.160 – 45.490,9.220`，获取日期 2026-10-20。

- © OpenStreetMap contributors — https://www.openstreetmap.org/copyright
- 许可：Open Database License (ODbL) 1.0 — https://opendatacommons.org/licenses/odbl/1-0/
- `milan.js` 是 ODbL 意义上的"衍生数据库"（路口/路段建图、投影到局部米坐标、道路等级与估算车速），
  按 ODbL 同样以 ODbL 提供。本仓库的 MIT 许可只覆盖代码，不覆盖这些数据。

`milan.js` is a derived database under ODbL (intersections/segments graph, local-metre projection,
road classes and estimated urban speeds). It is made available under the same ODbL terms.
The repository's MIT license covers the code only, not this data.
